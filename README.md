##  Cómo Jugar
1. **[A] / [D]:** Moverse a la izquierda o derecha entre los 3 carriles.
2. **[Espacio]:** Saltar sobre los vehículos.
3. **[F]:** Disparar balas para eliminar zombis y destruir vehículos.
4. Sobrevive el mayor tiempo posible para sumar puntos por distancia y recolecta las monedas amarillas.
